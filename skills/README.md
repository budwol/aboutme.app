# Skills

The repository skills are general-purpose and work as a coordinated review set.

For a complete review, start with `$quality-review`. It coordinates the focused skills in this order:

1. `$data-contract`
2. `$architecture-review`
3. `$frontend-quality` and, when implementation is needed, `$frontend-engineer`
4. `$performance-engineer`
5. `$test-engineer`
6. `$documentation-keeper`
7. `$ci-cd-engineer`
8. `$release-engineer`

Each specialist can also be invoked directly for a focused task.
