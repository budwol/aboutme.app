# Skills

The repository skills are general-purpose and work as a coordinated review set.

For a complete review, start with `$quality-review`. It coordinates the focused skills in this order:

1. `$data-contract`
2. `$architecture-review`
3. `$ux-designer`
4. `$frontend-quality` and, when implementation is needed, `$frontend-engineer`
5. `$performance-engineer`
6. `$test-engineer`
7. `$documentation-keeper`
8. `$ci-cd-engineer`
9. `$release-engineer`

Each specialist can also be invoked directly for a focused task.

Use `$hr-content` when the review or implementation concerns CV, portfolio, profile, or application content.
